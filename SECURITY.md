# Політика безпеки

## Повідомлення про вразливості

Якщо ви знайшли проблему безпеки, **не створюйте публічний issue**.

Надішліть опис на GitHub через [Security Advisories](https://github.com/meleudas/citizen_back/security/advisories/new) або створіть приватний issue з міткою `security` (якщо доступно).

Ми намагаємось відповісти протягом **72 годин**.

## Рекомендації для розробників

- **Ніколи** не комітьте файл `.env` — використовуйте `.env.example` як шаблон.
- Зберігайте секрети в змінних середовища або GitHub Secrets.
- При компрометації JWT-секретів — негайно згенеруйте нові значення для:
  - `JWT_ACCESS_SECRET`
  - `JWT_REFRESH_SECRET`
  - `JWT_RESET_SECRET`
- Якщо `.env` колись потрапив у git-історію — **обов'язково ротуйте** всі секрети (MongoDB, Cloudinary, Redis, JWT) і розгляньте очищення історії через `git filter-repo`.
